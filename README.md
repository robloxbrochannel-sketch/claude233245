# Pip's Little Post

A cozy, storybook route-drawing puzzle game. Help Pip the snail deliver letters around a woodland village and return to the post office before the ink runs out.

Open `index.html` in a browser to play. Drag or tap adjacent squares, or use the arrow keys / WASD. Retrace your last step to undo it. Complete chapters to unlock the next one; progress is saved locally.

Built with vanilla HTML, CSS, and Canvas. No build step or dependencies required.
